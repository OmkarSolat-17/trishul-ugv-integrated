# Results, Benchmarks & Demonstration Records

> **Owner**: Integration Lead (in coordination with all leads)

This directory is designated for storing demonstration outputs, milestone verification records, and performance metrics.

## Guidelines
- **Committed Files**: Summary tables, test logs, lightweight markdown benchmark reports, and compressed visualization screenshots (`.png`, `.jpg`).
- **Ignored Files**: Heavy runtime data such as raw ROS bag files (`*.db3`, `*.mcap`), video screen recordings (`*.mp4`), or large point cloud dumps. These must not be committed to Git (configured in `.gitignore`).
